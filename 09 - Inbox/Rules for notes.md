# [[Rules for notes]]

## Headlines & Separators

- We don't use `---`
- Level 1 Headline is just for the tittle
- Notes should keep the headlines minimal (Bigger docs like MoCs can have more)
- One blank like after a title but none before

## Bullet list

- Never include blank lines
