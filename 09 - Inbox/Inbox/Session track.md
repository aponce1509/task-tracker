Pensar como gestionar las referencias web de aprendizaje es un dolor de huevos.

1. Readwise no es muy útil
2. Zotero no está mal pues puedes agregar links pero está aislado ahí
3. Los bookmarks tienen su utilidad 
4. Hay muchas cosas más en la web que quieres guardar
5. Tienes que ser capaz de unir con tu trabajo

Veamos estos puntos poco a poco.

## Objetive

Quiero ser capaz de guardar todo lo que haces en la web.

1. Artículos y videos. Te llega mediante algún feed y tiene algo que quieres aprender, te resulta interesante o inspirador.
2. Sesiones de trabajo. Estas trabajando con algo que no manejas mucho y estas aprendiendo mucho.
3. Links con información: una entrada de una documentación, 
4. Herramientas web útiles: calculadora, base de datos web, ...
5. Páginas inspiradoras para un proyecto: Puedes sacar ideas para un frontend...

### Requirements

- Los link de aprendizaje solo se guardan en el ordenador personal
- Las sessions se hacen manualmente en nvim y están en la nota de la task
- Usamos los bookmarks para herramientas solo
- Las inspiradoras van al reader, junto con reader y videos.
- Si queremos hacer una nota, también manual. Las notas solo se hacen cuando estás aprendiendo activamente, no en medio de un proyecto.
- Toda referencia formal va a zotero: links, libros, cursos.
	- Si las notas están en reader añadir link
