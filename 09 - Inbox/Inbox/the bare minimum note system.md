## Methodology

### PAR

- each P/A/R has a note where we track all the project. Three types: active,
  archive, and future.

### Indexing

- All notes should be indexed

### Note movement

- Each PAR has a folder with the notes.
- Only move completed Note
- Indexing is mandatory
- each Friday at home you have to clean: desktop, emails and notes. Also you
  review your goals and the long term objetives.

### Note Search

  - Links literature notes using readwise

### Work Routine

1. Open email and jira
2. Start the day reading the status point and select all the task for the day.
   - Check that no task is missing: active project todos list and any calendar
     task
3. Open the task note and start working on it:
   1. Create a note for the task.
   2. Write subtasks
   3. Complete the task
   4. While completing the task add important info related to the task
   5. If the info of the task is relevant move to second brain
   6. Fulfill the done definition
   7. Add metadata to the task
   8. Archive the task
4. At the end of the day, review the tasks, completed ones and not completed and
   create a new status point

## Tasks

Custom program: tui (terminal user interface) quite simple.

We define this hierarchy:

- List (project related)
- Issue (task)
  - Types of issues: Task, Bug, Improvement, Doc, Support
  - Labels
- Task (subtask)

1. First display all the tasks in a list, you can add new tasks, mark as done
   and delete tasks.
2. Group the tasks by list, the default one is the inbox.
3. Storage
4. Add metadata for each task:
   - Priority: Standard values -> -100, 0, 100, 200: Non need, Low, Medium, High
   - Due date: Data to finish the task
   - Tags: just to add a group by key and for display. p.e. Appointment 🏥
   - Tracking Flag
5. Default Order: Due Date, Priority. Divide task by calendar task and the
   others.
6. Project metadata: active in this sprint, sprint objective.
7. Planner: Show all the list: active in this sprint and others. Show due dates
   for all the lists.
8. Today Pane: you can select task that will be added here. You want to see the
   daily note, the last status and not completed tasks.
