# Capture Example - Lazy Video

See the example in: [[lazy_nvim explained - TJ video]]

Now we want to capture a video that we think it is useful.

This example can be used to anything that can saved to reader.

## Some context

The main problem with this kind of notes is that are a little bit random, the
don't belong to any project you are working on. The belong to thing that you are
interesting in:

- productivity
- programming
- nvim

and so on.

## Differences by type

- Articles is the same if find at random. If is related to a project it just
  make easier finding where to put the capture.
- Twits is the same as a video

## Consuming articles from the mobile phone

- You lose the ability of having a markdown file.
- Don't archive the reader until you add it to a reference.

## The process

<!-- NOTE: #output/workflow -->

1. Save it to Reader, you will use it for general comments and for future
   consumption.
2. Create a note for the video
3. See it and take notes (reader and the note)
4. Find a PAR where you can put this content and add it to the Reference List
5. Archive the reader: tags
6. Clean up the note:
   1. Tags: why it is saved (literature tag) and which type of docu is.
   2. Move: to the PAR dir.
