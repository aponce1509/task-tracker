# task-tui

Create system for managing task. This system should have and TUI for controlling
it. It should have integration with nvim

## Similar tools

- Taskwariors is a good tool for managing task: <https://taskwarrior.org/>
- taskwarior-tui is a TUI for taskwarior:
  <https://github.com/kdheepak/taskwarrior-tui>
- taskwarior.nvim: <https://github.com/ribelo/taskwarrior.nvim>

## what is not

- We don't want a planer, just to manage todo files better

## Vamos a empezar simple
