# [[The CODE Process]]


Antes de ponerte a trabajar en cualquier cosa piensa en que parte estas:

- Convergente o Divergente
- Convergente
	- Capturamos
	- Al acabar el día, semana, tarea, etc ENTONCES ordenas
- Divergente
	- Consumimos las capturas para hacer algo concreto
	- Definimos que queremos hacer y como lo hacemos
	- Consumimos las notas capturadas y creamos notas/productos intermedias
- Ejemplo
	- Tarea: Hacer un modelo de clustering que funcione con variables categoricas

## Capture

Consiste en almacenar todo lo que te rodea

- Arte
- Musica
- Pelis
- Libros
- Comentarios de algunos de estos

Pero también de aquellas cosas que te surgen en la cabeza

- Ideas
- Reflexiones
- Idea de producto
- Solución a un problema complejo

## Distill

The ideas here:
- Move the polishing of the note to later SO YOU DON'T waste time in bad captures
- Improve the note by:
	- Highlighting
	- Adding information
	- Cleaning the Note
	- Add it to an index
- Internal Notes
	- add a new thought perspectives
- External Notes
	- Remove thing you don't need
	- Group highlight and makes summaries (AI help)
	- Add comments
	- Progressive Summarisation
	- Create Index/Reviews
	- As Summary -> Active learning
	- Extract the bases
	- Practice

## Express

This does not means that you have to use distilled note to make some announcement or tweet. This means to use the Intermediate Packets from other time and use them:

- Distilled Notes
- Ideas other things that didn't ended in a project
- Code module
- Other kind of documents
	- Slide
	- Graphic
	- Agendas
	- Plan
	- Kanban (time used for instance)
- External documents, libs or even persons that can help with
