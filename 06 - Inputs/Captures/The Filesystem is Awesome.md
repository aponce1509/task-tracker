# [[The Filesystem is Awesome]]

> [!abstract] Video by [[@rybkr]]
> - A path is a sequential instruction route, not a static address.
> - Filesystems resolve paths step-by-step using directory tables linked to inodes.
> - Files and directories share the same storage structure with distinct types defined by single characters.
> - Hard links share inodes while symbolic links are separate files containing text paths.
