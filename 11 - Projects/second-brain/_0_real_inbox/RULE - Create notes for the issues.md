# [[RULE - Create notes for the issues]]


> [!important] 
> Spend some time in the issue creation. Is way of following this: [[Cuando aprendas define fase de divergencia y convergencia]].

You have a list of issues and issue inbox. Keeping this clean and with priorities can help you in:

1. Deciding what you have to do to complete the project
2. Keep track the things you can do for the project
3. [[Keeping the Focus]] on the task you have to complete
4. Force yourself to define divergence and converge workflows.
