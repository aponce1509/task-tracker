## Bases

The idea is to have some key bases for:
- Common complex searches
- Entry points:
	- Index root
	- All paras
- Linked bases for special notes
	- PARAS Notes
	- Categories

## Tags

> [!note] Definition
> Special type of property that can be added directly to the doc just adding `#` and a word.


Obsidian has special ways of searching using tags, so its usage really interesting.


> [!attention] Rules
> - Try to add them in the property not using the `#` in the middle of the doc.
> - inline tags are allowed but not as the norm.
> - All the tags must be included in the file [[Tags Reference]]
> - When a new tag is created you must follow the [[New Tag workflow]]
