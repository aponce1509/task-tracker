Drives [[WORKFLOWS - New PAR]].

- Argument: `<name> [project|area|resource]`
- Load: `obsidian-vault-notes`, `note-issue`, `project-journaling`
- Steps
	- Search the PAR notes and the archive for a match; offer reactivation
	- Ask the anchor: objective, boundaries or sources
	- Create the PAR note from the PARA Note template and its folder
	- Take the brain dump from the user; propose links to existing notes and loose notes to attach
	- Project: create the journal from the template and the first issues
	- Propose the link from the parent area or the root
- Output: files created, links proposed, first issues
- Rules
	- Never invent the anchor or the brain dump; only structure them
	- Loose notes get `paras` only after approval
