# The Module - The minimum learning magnitude

> [!abstract] The smallest unit that a learning project plans
> - A module is one week of learning, with one objective and known parts of a source to read.
> - Once a module starts, I do not stop until I have reviewed all its content.

Following [[How to be an effective self-learner]], a learning project must define what to learn before it starts. That unit is the module.

## Definition

- It is something I can learn in one week.
- I know what to read or consume to learn it.
- A set of modules forms a course ([[The Syllabus System]]).
- It has a defined objective.

The module is the old "topic" of this note. It is not the `topic-index` subtype, which is the index of a domain.

## Example

The best example is [[Capture Example - Rust Crates]]:

- I want to learn how tests are used in Rust.
- It is small.
- It is a part of something bigger.
- It is bounded: I know where to read.
