# [[Do Not miss incomplete notes - Note Status]]


> [!note] Definition
> 1. A group of tags designed to track the lifecycle and completion state of notes and project tasks.
> 2. Primarily used to ensure that incomplete items are not forgotten or lost in the system.

#todo needed note but need to be remade from scratch

## Status Tags

1. `#_wip`: (Work In Progress) A general-purpose tag for any note or task currently under active development.
2. `#_not_solved`: Specific to projects; indicates a problem or roadblock that has been identified but lacks a solution.
3. `#_not_implemented`: Used for features, ideas, or steps that have been decided upon but not yet executed.
4. `#_tech_debt`: Identifies areas that require future refactoring, cleanup, or optimisation due to a temporary "quick fix."

## Usage Rules

1. Use `#_wip` for any creative or organisational process regardless of the context.
2. Reserve project-specific tags (`#_not_solved`, `#_not_implemented`, `#_tech_debt`) for technical or goal-oriented workflows.
3. Remove or update tags as soon as the status changes to maintain an accurate "To-Do" perspective.
