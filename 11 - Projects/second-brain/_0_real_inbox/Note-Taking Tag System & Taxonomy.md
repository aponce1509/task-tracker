# [[Note-Taking Tag System & Taxonomy]]

> [!important] 
> These are the system tag. We use these tags mostly for status, curation, precedence and usage information 

With this system we want to solve the following question:

- Unorganised Notes -> Inbox
- Which notes comes from external sources -> External
- Which things could I use in other projects -> Intermediate
- What can I learn or see today -> Databases
- Which are curated notes -> Distill
- Which are my captures about this topic -> Capture

## Note Generic Categories

1.  **[[Second Brain Inbox]]**
    - Entry point for new, unorganized ideas.
    - Focuses on quick capture to be organized later.
    - Location: `09 - Inbox` folder.
    - Tag: `#_inbox`
2.  [[External Notes]]
    - Derived from outside sources (quotes, ideas, annotations).
    - Usually includes a reference to the origin.
    - Tag: `#_external`
3. [[Intermediate Products]]
    - Artifacts or drafts created during a project.
    - Stored because they may provide future value.
    - Tag: `#_intermediate`
4. Logging Items
5. Just Notes
6.  [[References Database]]: Itemes in the data base.
    - Tracking content for consumption or education within Obsidian.
    - Tag `#_to_consume`: Content waiting to be read/watched.
    - Tag `#_to_learn`: Specific courses or tutorials for skill acquisition.

## Distillation Process: [[Distill - CODE]]

1.  **Capture Phase**
    - Initial recording of internal reflections or external data.
    - No time is spent on refinement or formatting.
    - Tag: `#_capture`
2.  **Refinement Phase**
    - Occurs when a note is reused or revisited.
    - Involves underlining, formatting, and adding commentary.
    - Tag transitions from `#_capture` to `#_distill`.
3.  **Distillation Workflow**
    - Give the note a suggestive, clear title.
    - Ensure the main idea is scannable/readable at a glance.
    - Verify if the note has been linked or used elsewhere.

## [[Do Not miss incomplete notes - Note Status]]

1.  **Work in Progress**
    - Used for any item currently under development.
    - Tag: `#_wip`
2.  **Pending Technical/Project Tasks**
    - `#_not_solved`: Unresolved issues.
    - `#_not_implemented`: Planned features not yet built.
    - `#_tech_debt`: Code or logic that requires future refactoring.
