# [[WORKFLOWS - End Day]]

> [!summary]
> Shut down the day intentionally, clear the workspace, and build the bridge for tomorrow.

**Timecap: 5 Minutes**

Every evening before closing the vault:
1. **Triage Today's Tasks:** Mark completed items. Move uncompleted tasks back to the `[[Week Note]]` backlog or reschedule them.
2. **Log Quick Wins:** Write 1–2 bullet points on what you actually achieved or discovered today.
3. **Non Planned task**: Include all the unexpected tasks.
4. **Build the Hemingway Bridge:** Leave a specific, incomplete prompt at the bottom of your note for tomorrow. 
	- *Example: "Tomorrow morning: Open the report draft and write the introduction paragraph using the data from..."*
5. **Close the Tabs:** Close all open note panes in Obsidian to start tomorrow with a clean visual slate.
