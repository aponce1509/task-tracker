# [[Convergence and Divergence]]


![[Pasted image 20260215190445.png]]
## Definition of Concepts

1. **Divergence**: The "expanding" phase of thinking where you gather information, explore various perspectives, and allow for chaos. It is about quantity over quality and making broad connections.
2. **Convergence**: The "narrowing" phase where you filter, synthesize, and organize your findings into a specific outcome or insight. It is about focus, utility, and closing loops.

## Relationship with the CODE Process

The CODE framework (Capture, Organize, Distill, Express) functions as a rhythmic movement between these two states:

1. **Capture (Divergence)**: Openly collecting interesting snippets, ideas, and bookmarks without immediate judgment.
2. **Organize (Divergence/Transition)**: Placing notes into broad contexts (like the PARA method) to see how they relate to various projects.
3. **Distill (Convergence)**: Using techniques like Progressive Summarization to find the "signal in the noise," narrowing down a long note to its core essence.
4. **Express (Convergence)**: Producing a final output—a blog post, a report, or a project—where all previous research is funneled into a single, cohesive result.

## Key Differences

| Phase | Goal | Mindset |
| :--- | :--- | :--- |
| **Divergence** | Exploration | Curious, Non-judgmental, Broad |
| **Convergence** | Execution | Critical, Selective, Focused |
