# [[How to manage Task management]]

## Opciones

- Uso del wip para notas incompletas
- Una nota centralizada donde poner las issues y ya
- poner `- [ ]` y usar el plugin de tasks

## WIP

Independientemente de lo elegido, todas las notas incompletas llevan el wip. Estas notas se completan cuando las usemos nuevamente o puede ser una tarea.

> [!important] 
> No confundir wip con capture. Una captura sin destilar es simplemente eso. Un wip es una nota que hemos emepezado pero que se puede mejorar, se puede destilar.

## Nota central

Es lo más cómodo y lo que vamos a hacer. Simplemente tienes que tener abierta la nota de los issues e incluso puedes hacerte una base inline para ver los wips que tienes. 

Aqui creamos la base con los issues related. Crear notas para issues independientes tiene valor: [[This is really a Task]]
