# [[Zotero - The ultimate reference manager]]

> [!abstract] Zotero is my own internet; the notes are my notebook
> - Every reference important for learning lives in Zotero, not in the vault.
> - Zotero tags link a reference to a PAR and classify it by relevance, so references stay decoupled from notes.
> - A note starts only when I capture from the reference.

## Key features

- Tags: a reference gets the PAR it serves and its relevance as Zotero tags. No vault query is needed to list the references.
- Files can live in multiple places (collections) at once.
- Custom references hold material with no standard type, and notes can be created from them.
- Notes can be attached to a reference.

## From reference to note

A note starts only with a capture: highlights and extracts from the reference, as in [[Capture Example - Rust Crates]]. The highlights follow [[Notes Colours Rules]].
