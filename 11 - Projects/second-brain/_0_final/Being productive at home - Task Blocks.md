# [[Being productive at home - Task Blocks]]

> [!abstract] Block the time, list the tasks, then start
> - Select the objective, take some issues and start.
> - The time block is mandatory.
> - The task list is mandatory.

## Steps

- Select one objective: one PAR, or the focus of the week ([[WORKFLOWS - Start Week]]).
- Take some of its issues and list the tasks to do in this block. The plan of the day already holds them: [[WORKFLOWS - Start Day]].
- Block the time.
- Work on the tasks. That's it.

Based on [[Keeping the Focus]]. The block is made of real tasks: [[This is really a Task]].
