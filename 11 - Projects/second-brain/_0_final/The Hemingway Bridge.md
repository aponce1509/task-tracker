# [[The Hemingway Bridge]]

> [!abstract] Stop when the next step is clear
> - End a work session only when the next action is known, while there is still energy for it.
> - Write that next action down: the next session starts from it, not from zero.
> - In the vault the bridge is the `bridge` property of each PAR note, crossed at Start Day and written at End Day.

## Key ideas

1. **Strategic stopping**: end a session only when I know exactly what comes next.
2. **Momentum carry-over**: the energy of today bridges the gap to the next session.
3. **Island linking**: in [[The Archipelago of Ideas]], the bridge connects isolated thoughts into one narrative.

## Steps

1. Identify the next step of the project.
2. Stop while there is still clarity and energy to do it.
3. Write the next action, to resume without friction the next day.

## In the vault

- The `bridge` property of the PAR notes holds the next concrete action ([[Common Frontmatter Schemas & Specific Note Templates]]).
- [[WORKFLOWS - End Day]] writes the bridges; [[WORKFLOWS - Start Day]] crosses them. The Today dashboard shows them ([[The Workplace System]]).
