# Rust Quick Start

Install rust: <https://doc.rust-lang.org/book/ch01-01-installation.html>

## rustc

```bash
rustc --version
```

```bash
rustc doc
```

## Cargo

The commands you will need,
[see this link](https://doc.rust-lang.org/book/ch01-03-hello-cargo.html) for
more details

```bash
cargo new hello_cargo
cargo init
cargo build
cargo run
cargo check
cargo build --release
```
