# [[Second Brain Folder Structure]]

**Methodology:** Based on the [[PARA Methodology]].

### 📂 Core System Folders

| Folder | Name                 | Purpose / Definition                                                                         |
| :----- | :------------------- | :------------------------------------------------------------------------------------------- |
| **00** | **Map of Contents**  | Central hub for all MoC (Map of Content) files.                                              |
| **01** | **PAR**              | Primary index files for Projects, Areas, and Resources. Includes `_archive` and `_some_day`. |
| **02** | **Categories**       | Definition files for categories and content types. Includes `_types`.                        |
| **03** | **Permanent Active** | One folder per long-term, permanent interest (Max 12).                                       |
| **04** | **Bases**            | Central repository for all database-style notes.                                             |
| **05** | **Undefined**        | *Reserved for future system expansion.*                                                      |

### 📥 Capture & Action Folders

#### 06 - Inputs

*Definition: Raw extractions and data from external sources.*

* **General:** `Art`, `Chats`, `Clippings`, `ManualInputs`, `Highlights`, `Products`, `Recipes`
* **References:** `Bookmarks`, `Books`, `Films`, `Videos`

#### 07 - Daily

*Definition: Calendar-based notes and daily journals.*

#### 08 - Tasks

*Definition: Tracking issues, to-dos, and actionable notes.*

#### 09 - Inbox

*Definition: The "landing strip" for all new, unprocessed notes.*


### 🏛️ The PARA Framework

* **10 - Archive**
    * *Def:* Cold storage for completed projects or inactive interests.
* **11 - Projects**
    * *Def:* Active endeavors with a specific deadline and goal.
* **12 - Areas**
    * *Def:* Ongoing responsibilities that require a high standard over time.
* **13 - Resources**
    * *Def:* Interests or topics of general information.

### ⚙️ System Admin (Meta)

#### 99 - Meta

> This folder manages the "engine" of your Obsidian vault.
* **System Files:** `Attachments`, `Obsidian`, `Templates`, `Trash`
* **Tracking:** `Calendar`, `Habits`, `Metadata Fields`
* **Visuals:** `Excalidraw`, `Class`
