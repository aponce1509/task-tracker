# [[Mid Term Second Brain Outline]]


El objetivo de este outline es definir el estado actual del second brain

Partimos de estas notas:
- [[Second Brain Outline]]
- [[Notes a base system]]
- [[Second Brain Issues]]

Que tratamos de conseguir:
- Un sistema donde poder tracker conocimiento pasado
	- Nada super complejo
	- Una serie de indices que poder mirar para recuperar información
	- Cuaderno de notas para cuando aprendas algo
- Reducir la carga mental mientras mejoramos la productividad
	- Definir una metodologia de tareas
	- Diary of development
	- Tener claro que extraemos de este diario
- Incorporar la IA dentro de este sistema
Que no tratamos de conseguir:
- Ser la documentación por defecto de un proyecto

Para esto es necesario: [[Second Brain MVP]]

Pero sobre todo: Tener [[Alejandro's Mise-en-Place]] bien definida e interiorizada.
