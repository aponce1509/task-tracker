# [[Cuando aprendas define fase de divergencia y convergencia]]


> [!important] Problem
> Suele pasarte que te pones a aprender sobre algo:
> - NI Eres Productivo
> - NI Tomas Notas
> 
> Esto te ocurre porque empiezas a leer y vas "unhinged".
> 
> Por otro lado, cuando aprendes por tu cuenta no aplicas lo aprendido y por tanto no se te queda.

## Divergence Mode

El Divergence mode comienza siempre siempre para realizar una [[This is really a Task]]. No siempre que empecemos una tarea implica que tengamos que pasar por la divergencia.

#_wip 
Para esto definimos un workflow:
1. Crear una nota que ya se ordenara y limpiara: Divergence Index
2. Pon el objetivo de la divergencia. Definir cuando acabamos. Algunos ejemplos:
	1. Tipos de clusterings
	2. Leer un capitulo del Hull
3. Si tiene una solución haz un diagrama de esta
4. La tarea acaba con la limpieza del indice guarro creado
	1. Creamos notas aisladas
	2. Hacemos plan de convergencia

## Convergence Mode

Es importante distinguir aquí dos casos distintos:

1. Convergencia de una tarea de trabajo
2. Convergencia de un bloque de estudio

### Bloque de estudio

1. Construcción de la [[Reviews]]
2. Hay problemas? Hacerlos
3. Hablar con chatgpt un rato
	1. Recoger la discusion
4. Algo de código que pueda ser útil

### Tarea

1. Abrir una nota con comentarios y tareas
2. Definir el done requirements
3. Span de tiempo que esperas
4. Ir haciendo poco a poco
