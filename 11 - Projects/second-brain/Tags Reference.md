# [[Tags Reference]]

## Internal Tags

> [!note] 
> Internal notes start with `#_`. Te las tienes que saber al dedillo.

- Tags: Described in [[Note-Taking Tag System & Taxonomy]]
  - Not organised: `_inbox` -> ==This does not means ended note==
  - Comes from external: `_external`
  - Distillation level: `_capture`, `_distilled`
  - core elements development level: `_seed`, `_evergreen`
  - Reutilizable products: `_intermediate`
  - Status Tag: 
	  - `_not-solved`: question, doubt, problem... not solved
	  - `_not_implemented`: Feature, Idea, Requirement not implemented
	  - `_wip`: Anything that need development
  - References Status: To use in references that you may consume in the future.
	  - `_to_learn`
	  - `_to_consume`
	  - `_consuming`
	  - `_completed`
	  - `_dropped`
