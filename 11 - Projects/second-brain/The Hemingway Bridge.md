# [[The Hemingway Bridge]]

## Key Concepts

1. **Strategic Stopping**: End a work session only when you know exactly what happens or what needs to be done next.
2. **Momentum Carryover**: Use the "energy of today" to bridge the gap to the next session, preventing starting from zero.
3. **Island Linking**: In the context of the [[The Archipelago of Ideas]] it serves as the connection between isolated thoughts or data points to create a cohesive narrative.

## Implementation Steps

1. Identify the next step or plot point in your project.
2. Stop working while you still have the clarity and energy to execute that step.
3. Document the immediate next action so you can resume without friction the following day.
